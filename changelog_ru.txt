v2.9 - 2026-09-23
===============================================================================
Релизная версия. Все изменения из 2.8.5 плюс исправления документации.

Безопасность:
  - Права procfs ужесточены: 0666 -> 0644 (debug, auto_interval)
  - Права procfs ужесточены: 0222 -> 0200 (export, unexport, measure)
  - Только root может записывать в конфигурацию и управляющие записи

Исправления:
  - kthread_stop() вынесен из list_lock в sensor_interval_write
    Ранее установка interval в -1 вызывала dht_stop_poll() под
    list_lock, что приводило к сну в kthread_stop(). Теперь указатель
    потока сохраняется и очищается под блокировкой, kthread_stop()
    вызывается после освобождения блокировки.
  - Проверка NULL в dht_sensor_release перед proc_remove()
    Предотвращает потенциальный краш при выгрузке модуля, когда
    proc_dir равен NULL.
  - TOCTOU при регистрации датчика: добавлена проверка дубликата пина
    под list_lock перед созданием procfs-записей. Закрывает окно между
    начальной проверкой и proc_mkdir().

Документация:
  - README: вывод dmesg исправлен в соответствии с кодом
    Было: "[DHT]: DHT11/DHT22/AM2302 Temperature and Humidity Sensor Driver"
    Стало: "[DHT]: DHT Driver (c) 2026, Chapvic (v2.9)"
    Было: "[DHT]: procfs interface at /proc/sensors/dht/"
    Стало: "[DHT]: driver loaded - /proc/sensors/dht/ (max 32 sensors)"
  - README: раздел проверок перед сборкой исправлен
    Удалены ложные утверждения о проверках CONFIG_GPIOLIB/PROC_FS/MODULES
    Добавлено примечание о требованиях времени выполнения
  - README: список файлов репозитория обновлён (LICENSE, changelogs,
    ReleaseNotes)
  - README: таблица целей Make - убрано "config" из описания check
  - README: история версий обновлена всеми промежуточными версиями
  - README: устранение неполадок - строка CONFIG_GPIOLIB исправлена
  - README: все ссылки на версию обновлены с 2.8.5 на 2.9
  - README_RU.md: полный русский перевод, 28 разделов

Инфраструктура:
