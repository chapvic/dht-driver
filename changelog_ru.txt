Журнал изменений драйвера DHT
=============================

Версия 2.8.5 (2026-01-15)
==========================

Система сборки
---------------
1. Исправлено размещение obj-m: теперь на верхнем уровне перед ifdef KERNELRELEASE
   (Kbuild не находил модуль, когда obj-m был внутри блока ifdef)
2. Добавлен ручной depmod -a после modules_install
   (Kbuild пропускает depmod при отсутствии System.map, из-за чего modprobe не работает)
3. Добавлена цель uninstall с find для всех расширений сжатых модулей
   (.ko, .ko.xz, .ko.gz, .ko.zst, .ko.bz2, .ko.lz4)
4. ARCH и CROSS_COMPILE по умолчанию пустые (без предупреждений при нативной сборке)
5. Добавлена цель check: версия ядра, заголовки, CONFIG_GPIOLIB/PROC_FS/MODULES
6. Добавлена цель help со списком всех целей и переменных make
7. make (по умолчанию) теперь запускает check перед modules
8. depmod -a запускается после uninstall для обновления базы модулей

Поддержка DKMS
--------------
9. Добавлен dkms.conf с AUTOINSTALL=yes для автоматической пересборки при обновлении ядра
10. Команды DKMS описаны в README (add, install, remove)
11. dkms.conf включён в список файлов репозитория

Совместимость с ядрами
----------------------
12. Добавлен макрос DHT_PROC_OPS: proc_ops (5.6+) vs file_operations (до 5.6)
13. Добавлен макрос DHT_PDE_DATA: pde_data() (5.17+) vs PDE_DATA() (до 5.17)
14. Минимальная версия ядра: 5.0 (проверяется через make check)
15. Протестировано до ядра 6.18+ (Raspberry Pi 6.18.50+rpt-rpi-2712)

Исправления ошибок
------------------
16. Патч #13: atomic_cmpxchg без двойного отрицания
    (было: atomic_cmpxchg(&flag, 0, 1) == 1; исправлено: != 0)
17. Патч #15: last_attempt_time обновляется ПОСЛЕ успешного cmpxchg
    (обновлялся до, что обходило ограничение частоты при одновременном доступе)
18. Патч #16: iterate_dir() для проверки пустоты procfs перед удалением
    /proc/sensors (предотвращает удаление, когда другие драйверы имеют записи)

Документация
-------------
19. README.md переписан: 28 разделов, включая архитектуру протокола DHT,
    таблицу совместимости ядер, таблицу стабильности API
20. README_RU.md: полный перевод на русский, 28 разделов
21. Руководство по установке DKMS с проверкой и процедурами обновления
22. Примеры на Bash: 6 скриптов (базовое чтение, мониторинг, CSV, мульти-сенсор,
    порог, регистрация из файла конфигурации)
23. Примеры на Python: 5 скриптов + unit-файл systemd (базовый, CSV, ручной,
    мульти-сенсор, демон syslog)
24. Сервис systemd: 3 способа (modules-load, сервис modprobe, полный сервис)
25. Раздел «Архитектура»: kref, вытеснение, поток опроса, безопасная выгрузка,
    диаграмма потока измерений
26. Таблица устранения неполадок с типичными проблемами и решениями


Версия 2.8 (2026-01-10)
========================

Начальный публичный релиз.

Известные проблемы, исправленные в 2.8.5:
- obj-m внутри ifdef KERNELRELEASE (ошибка сборки)
- Нет depmod после modules_install (ошибка modprobe)
- uninstall искал только .ko (пропускал .ko.xz)
- proc_ops не обрабатывался для ядра 5.6+
- PDE_DATA переименован в pde_data в 5.17+ не обрабатывалось
- Нет поддержки DKMS
- Двойное отрицание в atomic_cmpxchg
- last_attempt_time устанавливался до cmpxchg (гонка ограничения частоты)
- Удаление /proc/sensors без проверки наличия других записей
