# Драйвер датчиков температуры и влажности DHT11/DHT22/AM2303

**Версия:** 2.8.4  
**Автор:** Chapvic  
**Лицензия:** GPL v3  
**Совместимость:** ядро Linux 5.10+ (тестировалось на Raspberry Pi OS 64-bit)

## Обзор

Модуль ядра Linux для чтения данных о температуре и влажности с датчиков DHT11, DHT22 и AM2303, подключённых к GPIO-пинам Raspberry Pi. Драйвер создаёт интерфейс procfs в `/proc/sensors/dht/` для управления регистрацией датчиков, конфигурацией и получением данных.

## Возможности

- Динамическая регистрация/удаление датчиков через procfs
- Индивидуальные proc-записи для каждого датчика: температура, влажность, статус, конфигурация
- Фоновый поток опроса с настраиваемым интервалом
- Глобальный режим авто-опроса с общим интервалом
- Кэширование базы GPIO-чипа для быстрой регистрации нескольких датчиков на Pi 3/4/5
- Наносекундная точность измерения импульсов для надёжного чтения на всех моделях Pi
- Rate limiting для всех измерений (ручных и авто-опрос)
- Безопасная выгрузка модуля со счётчиком ссылок
- Разделяемый `/proc/sensors`: сосуществует с другими драйверами сенсоров
- Файл конфигурации: опциональный `/etc/default/dht` для авторегистрации при загрузке

## Procfs-интерфейс

### Глобальные записи: `/proc/sensors/dht/`

| Запись | Режим | Описание |
|-------|-------|---------|
| `debug` | rw | Отладочный вывод: 0 = выкл (по умолчанию), 1 = вкл |
| `version` | r | Версия драйвера |
| `export` | w | Записать номер BCM-пина для регистрации датчика |
| `unexport` | w | Записать номер BCM-пина для удаления датчика |
| `auto_interval` | rw | Глобальный интервал авто-опроса (2-60, -1 = выкл) |

### Записи датчика: `/proc/sensors/dht/gpio<пин>/`

| Запись | Режим | Описание |
|-------|-------|---------|
| `pin` | r | Номер BCM GPIO-пина |
| `interval` | rw | Интервал авто-опроса в секундах (2-60, -1 = выкл) |
| `measure` | w | Записать "1" для запуска измерения (игнорируется при активном авто-опросе) |
| `status_code` | r | Код ошибки (0 = успех) |
| `status_text` | r | Описание ошибки |
| `value` | r | "H=\<влажность\>
T=\<температура\>
" |
| `info` | r | Тип датчика + время регистрации |
| `timestamp` | r | Unix-время последнего измерения |

## Быстрый старт

### Сборка и установка

```bash
make
sudo make install
sudo modprobe dht
```

### Регистрация датчика

```bash
echo 23 | sudo tee /proc/sensors/dht/export
```

### Чтение значений

```bash
cat /proc/sensors/dht/gpio23/value
# Вывод: H=54.6
#         T=24.3
```

### Включение авто-опроса

```bash
echo 10 | sudo tee /proc/sensors/dht/auto_interval
```

### Удаление датчика

```bash
echo 23 | sudo tee /proc/sensors/dht/unexport
```

## Файл конфигурации

Опциональный: `/etc/default/dht` — читается при загрузке модуля.

```bash
# /etc/default/dht
DEBUG=1
AUTO_INTERVAL=10
SENSOR=4            # DHT22 на GPIO4, использует глобальный интервал
SENSOR=17,5         # DHT11 на GPIO17, опрос каждые 5 секунд
SENSOR=22           # Датчик на GPIO22, без авто-опроса
```

| Параметр | Описание |
|----------|----------|
| `DEBUG` | Включить отладочный вывод (эквивалент `DEBUG=1`) |
| `DEBUG=0\|1` | Явно включить/выключить отладку |
| `AUTO_INTERVAL=n` | Глобальный интервал авто-опроса в секундах (2-60) |
| `SENSOR=<пин>` | Зарегистрировать датчик на указанном BCM-пине |
| `SENSOR=<пин>,<n>` | Зарегистрировать с индивидуальным интервалом опроса |

## Поддерживаемое оборудование

| Датчик | Температура | Влажность | Примечания |
|--------|-------------|-----------|------------|
| DHT11 | 0-50 C, +/-2 C | 20-90%, +/-5% | Целые значения, низкое разрешение |
| DHT22/AM2302 | -40-80 C, +/-0.5 C | 0-100%, +/-2% | Десятичные значения, высокое разрешение |

Тестировалось на: Raspberry Pi 3, 4, 5 (все используют разные GPIO-контроллеры).

## Коды ошибок

| Код | Имя | Описание |
|-----|-----|----------|
| 0 | ERR_SUCCESS | Операция выполнена успешно |
| 1 | ERR_PIN_INVALID | Пин вне допустимого диапазона (0-27) |
| 2 | ERR_GPIO_REQUEST | Не удалось запросить или найти GPIO-дескриптор |
| 3 | ERR_READ_FAILED | Ошибка чтения данных (контрольная сумма, таймаут) |
| 4 | ERR_AUTO_MODE | Ручное измерение при активном авто-опросе |
| 5 | ERR_TOO_SOON | Rate limit: минимум 2 секунды между измерениями |

## Устранение неполадок

| Симптом | Причина | Решение |
|---------|---------|---------|
| `status_code=3` | Ошибка чтения датчика | Проверьте проводку, pull-up резистор (4.7k-10k) |
| `status_code=4` | Ручное измерение в режиме авто-опроса | Отключите auto_interval или индивидуальный интервал |
| `status_code=5` | Слишком быстрое измерение | Подождите минимум 2 секунды между ручными чтениями |
| Отрицательная температура читается как положительная (DHT22) | Исправлено в v2.8.3 | Обновите до последней версии |
| Каждое второе измерение пропускается | Инвертированный флаг measuring, исправлено в v2.8.4 | Обновите до последней версии |
