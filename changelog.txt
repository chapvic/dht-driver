v2.9 - 2026-09-23
===============================================================================
Release version. All changes from 2.8.5 plus documentation fixes.

Security:
  - procfs permissions hardened: 0666 -> 0644 (debug, auto_interval)
  - procfs permissions hardened: 0222 -> 0200 (export, unexport, measure)
  - Only root can write to configuration and control entries

Fixes:
  - kthread_stop() moved out of list_lock in sensor_interval_write
    Previously, setting interval to -1 called dht_stop_poll() under
    list_lock, which sleeps in kthread_stop(). Now the thread pointer
    is saved and cleared under lock, kthread_stop() called after unlock.
  - NULL guard in dht_sensor_release before proc_remove()
    Prevents potential crash during module unload when proc_dir is NULL.
  - TOCTOU race in sensor registration: added duplicate pin check under
    list_lock before creating procfs entries. Closes the window between
    initial check and proc_mkdir().

Documentation:
  - README: dmesg output corrected to match actual code output
    Was: "[DHT]: DHT11/DHT22/AM2302 Temperature and Humidity Sensor Driver"
    Now: "[DHT]: DHT Driver (c) 2026, Chapvic (v2.9)"
    Was: "[DHT]: procfs interface at /proc/sensors/dht/"
    Now: "[DHT]: driver loaded - /proc/sensors/dht/ (max 32 sensors)"
  - README: Pre-build Checks section corrected
    Removed false claims about CONFIG_GPIOLIB/PROC_FS/MODULES checks
    Added note about runtime requirements
  - README: Files in This Repository updated with LICENSE, changelogs,
    ReleaseNotes
  - README: Make Targets table - removed "config" from check description
  - README: Version History updated with all intermediate versions
  - README: Troubleshooting - CONFIG_GPIOLIB warning row corrected
  - README: All version references updated from 2.8.5 to 2.9
  - README_RU.md: Full Russian translation, 28 sections

Infrastructure:
  - LICENSE file added (GPLv3)
  - changelog.txt / changelog_ru.txt created
  - ReleaseNotes.md created for GitHub releases
