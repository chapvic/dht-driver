DHT Driver Changelog
=====================

Version 2.8.5 (2026-01-15)
==========================

Build System
------------
1. Fixed obj-m placement: now at top level before ifdef KERNELRELEASE
   (Kbuild could not find the module when obj-m was inside the ifdef block)
2. Added manual depmod -a after modules_install
   (Kbuild skips depmod when System.map is missing, causing modprobe to fail)
3. Added uninstall target with find for all compressed module extensions
   (.ko, .ko.xz, .ko.gz, .ko.zst, .ko.bz2, .ko.lz4)
4. ARCH and CROSS_COMPILE default to empty (no warnings on native build)
5. Added check target: kernel version, headers, CONFIG_GPIOLIB/PROC_FS/MODULES
6. Added help target listing all make targets and variables
7. make (default) now runs check before modules
8. depmod -a runs after uninstall to update module database

DKMS Support
------------
9. Added dkms.conf with AUTOINSTALL=yes for automatic rebuild on kernel update
10. DKMS commands documented in README (add, install, remove)
11. dkms.conf included in repository file list

Kernel Compatibility
--------------------
12. Added DHT_PROC_OPS macro: proc_ops (5.6+) vs file_operations (pre-5.6)
13. Added DHT_PDE_DATA macro: pde_data() (5.17+) vs PDE_DATA() (pre-5.17)
14. Minimum kernel version: 5.0 (enforced by make check)
15. Tested through kernel 6.18+ (Raspberry Pi 6.18.50+rpt-rpi-2712)

Bug Fixes
---------
16. Patch #13: atomic_cmpxchg without double negation
    (was: atomic_cmpxchg(&flag, 0, 1) == 1; fixed: atomic_cmpxchg(&flag, 0, 1) != 0)
17. Patch #15: last_attempt_time updated AFTER successful cmpxchg
    (was updated before, causing rate-limit bypass on concurrent access)
18. Patch #16: iterate_dir() for procfs empty check before removing
    /proc/sensors (prevents removal when other drivers have entries)

Documentation
-------------
19. README.md rewritten: 28 sections including DHT protocol architecture,
    kernel compatibility table, API stability table
20. README_RU.md: full Russian translation, 28 sections
21. DKMS installation guide with verification and update procedures
22. Bash examples: 6 scripts (basic read, monitoring, CSV, multi-sensor,
    threshold, config-file registration)
23. Python examples: 5 scripts + systemd unit file (basic, CSV, manual,
    multi-sensor, syslog daemon)
24. systemd service: 3 methods (modules-load, modprobe service, full service)
25. Architecture section: kref, preemption, poll thread, safe unload,
    measurement flow diagram
26. Troubleshooting table with common issues and solutions


Version 2.8 (2026-01-10)
========================

Initial public release.

Known issues fixed in 2.8.5:
- obj-m inside ifdef KERNELRELEASE (build failure)
- No depmod after modules_install (modprobe failure)
- uninstall only searched for .ko (missed .ko.xz)
- proc_ops not handled for kernel 5.6+
- PDE_DATA renamed to pde_data in 5.17+ not handled
- No DKMS support
- atomic_cmpxchg double negation
- last_attempt_time set before cmpxchg (rate-limit race)
- /proc/sensors removal without checking for other entries
