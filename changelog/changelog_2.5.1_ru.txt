Журнал изменений драйвера DHT GPIO
===================================

Версия 2.5.1 (2026-09-19)
--------------------------

Исправление: rate limiting для автоопроса

  * Ограничение частоты опроса (MEAS_MIN_GAP = 2 с) теперь применяется
    ко ВСЕМ измерениям, а не только к ручным.

  * Ранее poll-поток полностью обходил rate limiting. При регистрации
    датчика с активным глобальным автоопросом начальное измерение во
    время регистрации проходило успешно, но poll-поток запускался
    мгновенно и пытался повторить чтение через ~24 мс — раньше
    минимального времени восстановления DHT-сенсора (2 с). Это вызывало
    3 подряд неудачных попытки (j=0, data=[0,0,0,0,0]) в dmesg сразу
    после регистрации.

  * Исправление: функция dht_do_measurement() теперь проверяет время
    с последней попытки независимо от флага "manual". При срабатывании
    rate limiting во время автоопроса измерение тихо пропускается
    (только debug-сообщение), данные последнего успешного измерения
    сохраняются. Ручные измерения по-прежнему возвращают ERR_TOO_SOON.

  * Результат: после регистрации с активным глобальным автоопросом
    dmesg показывает:
      [dht_gpio_23]: measurement OK - H=57.0% T=23.4 C
      [dht_gpio_23]: auto-poll enabled by global setting
      [dht_gpio_23]: poll thread started
      [dht_gpio_23]: registered successfully
      [dht_gpio_23]: auto-poll skipped - only 0s since last measurement
      ... (следующее чтение через полный интервал) ...
      [dht_gpio_23]: measurement OK - H=57.4% T=23.4 C

Изменённые файлы: dht.c (функция dht_do_measurement, ~5 строк)
Совместимость: без изменения API, полностью обратно совместим с v2.5
